NexusPay Engine

A digital wallet backend that can take money from one account to another without ever losing track of it.

  • Kafka decouples ledger writes from notifications, cutting API response latency by an estimated 40%.
  • A two-step intent/execute flow with PostgreSQL row-level locks and UUID ordering keeps transactions ACID-compliant, with no deadlocks and no double-spends.
  • Redis rate limiting, idempotency keys and stateless JWT auth block brute-force MPIN attempts and duplicate retries.
  • An agentic fraud detector watches transaction velocity and freezes suspicious accounts on its own; a RAG assistant answers questions about past transactions in plain English.

ExpenseIQ

An expense tracker an AI model can actually operate, built on the Model Context Protocol.

  • Exposes 15 financial tools — records, budgets, analytics — safely to LLMs such as Claude.
  • Fully asynchronous on aiosqlite for non-blocking I/O, deployed to a remote cloud environment over Streamable HTTP.
  • Workflows are fault tolerant: the model validates its own inputs, corrects miscategorised entries, and reads live dashboards through MCP Resources.
